# Парсер Cointelegraph

Собирает англоязычные статьи Cointelegraph в `data/articles.csv`: заголовок, полный текст,
дату публикации, исходные теги, пометки BTC/ETH, язык, URL, ID и время первого сохранения.
Даты сохраняются в UTC. В поле `language` всегда `en`; формат совместим с уже собранным CSV.

Можно загрузить доступную историю или следить за новыми публикациями.
Сохранённые URL пропускаются, в том числе после перезапуска.
Фильтра по темам нет: BTC/ETH — дополнительные пометки, а не условие отбора.
Разделы `/press-releases/`, `/research/` и `/commissioned/` исключены до скачивания страниц.

## Установка

Нужны Python 3.10+ и интернет. Открой PowerShell в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если окружение и зависимости уже установлены, повторять эти команды не нужно.
В командах ниже используется Python из `.venv`, поэтому активировать среду необязательно.

## Как пользоваться

Для начала сохрани до 5 новых для CSV статей и дождись завершения:

```powershell
.\.venv\Scripts\python.exe main.py once --limit 5
```

Это не обязательно пять самых свежих статей: ссылки обходятся в порядке карт сайта.

Остальные режимы:

```powershell
# Один проход по двум последним опубликованным месячным картам сайта.
.\.venv\Scripts\python.exe main.py once

# Такой же проход, затем постоянные проверки каждые 5 минут.
.\.venv\Scripts\python.exe main.py watch

# Вся доступная история, начиная с ранних месячных карт, и завершение.
.\.venv\Scripts\python.exe main.py history

# История в обратном порядке месяцев: от свежих к старым.
.\.venv\Scripts\python.exe main.py history --reverse

# Вся история, затем постоянные проверки новых публикаций.
.\.venv\Scripts\python.exe main.py run
```

Если не указать режим, используется `run`. Источник один — `https://cointelegraph.com`.

`history --reverse` начинает с месяца самой свежей публикации в CSV и идёт назад:
например, октябрь → сентябрь → август. Уже сохранённые URL пропускаются.
Если CSV пуст, обход начинается с самой новой опубликованной карты.
Внутри месяца порядок статей не меняется; стартовый месяц обрабатывается целиком.
После остановки повтори ту же команду. Флаг также работает с `run` — после
обратной загрузки истории программа перейдёт к обычным проверкам новых публикаций.

`once` и `watch` берут два последних месяца из карт сайта, а не последние 60 дней.
Первый проход может занять время: нужно скачать все ещё отсутствующие в CSV статьи.
Если проход длится больше 5 минут, следующий начинается после его завершения.
Полнота сбора зависит от опубликованных ссылок и доступности страниц.

## Результат и остановка

- Все режимы дописывают один файл — `data/articles.csv`. Старые записи остаются.
- `saved ...` означает, что статья сохранена; `Next cycle ...` — ожидание следующей проверки.
- Для остановки нажми `Ctrl+C`. Чтобы продолжить, повтори команду: сохранённые URL будут пропущены.
- Запускай один экземпляр парсера за раз. После закрытия процесса сбор прекращается.
- Исправления уже сохранённых статей не отслеживаются. Ошибки выводятся в окно PowerShell.

Базовый интервал между запросами — 2 секунды. Если `robots.txt` требует большего,
парсер увеличивает интервал согласно `Crawl-delay` и `Request-rate`.
При запрете доступа останавливает сбор, при ограничении частоты в постоянном режиме ждёт.
Разрешение на сбор подтверждено владельцем проекта.

## Тесты и анализ

Офлайн-тесты — без скачивания новостей:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Для анализа CSV открой `eda.ipynb`, выбери Python из `.venv` и нажми **Run All**.
Если библиотеки анализа ещё не установлены:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-eda.txt
```

Хранилище отделено от сбора: в будущем CSV можно заменить на Postgres,
реализовав методы `contains(url)`, `save(article)` и `latest_published_at()`
(самая свежая дата публикации или `None`) и заменив создание хранилища в `main.py`.
