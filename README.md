
# CryptoScan: торговля криптовалютой на основе текстовых данных

## Описание 

Цель проекта — построить платформу, которая прогнозирует движение цен криптовалют
и принимает торговые решения на основе текстовых данных: новостей, постов
с криптофорумов, твитов и сообщений из Telegram-каналов. В перспективе
планируется добавить транскрибацию видео и стримов.

Для обучения и оценки моделей используются OHLCV-данные (Open, High, Low, Close,
Volume) торгуемых активов: они задают целевую переменную (изменение цены)
и дополняют текстовые признаки рыночными.

Платформа должна автоматически:
- собирать рыночные и текстовые данные из выбранных источников;
- очищать и преобразовывать их в признаки;
- дообучать модели на новых данных и подбирать гиперпараметры;
- выдавать прогнозы через API и отслеживать качество моделей.
