
# 📈 Trade Platform

## Описание 

Платформа для предиктивной торговли криптовалютой. Предикты основываются на ohlcv активах, новостях, криптофорумах, твитах, телеграмм каналах, возможно транскрибацией текстов видео/стримов. Платформа должна автоматизированно парсить данные, трансформировать их, дообучать модели на вычищенных данных, тюнить модели.
